# owaisazmal.github.io

The home page of `owaisazmal.github.io`. It points to [OwlLuna](https://owaisazmal.github.io/OwlLuna/).

Google takes a site's icon and name in search results from the root of its hostname, not from a project folder. Without this page, results for OwlLuna showed a globe and "GitHub Pages documentation". The icon and name set here apply to every site under this hostname.

- `index.html`: the page, with the favicon links and the site name (`WebSite` in the JSON-LD, `og:site_name`).
- `favicon.ico`, `icon-48.png`, `icon-192.png`, `apple-touch-icon.png`, `owl.png`: the OwlLuna icon, copied from the OwlLuna repository's `website/` folder.
- `robots.txt`: lists this site's sitemap and OwlLuna's. Crawlers read `robots.txt` only at the root of a hostname.
- `.nojekyll`: serves the files as they are.

The owl was designed by Safiya Sulaiman.
