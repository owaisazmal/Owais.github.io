# owaisazmal.github.io

The home page of `owaisazmal.github.io`: a short index of the sites under it.

Google takes a site's icon and name in search results from the root of its hostname, not from a project folder. Without this page, results for the sites here showed a globe and "GitHub Pages documentation". The icon and name set here apply to every site under this hostname.

- `index.html`: the page, with the favicon links and the site name (`WebSite` in the JSON-LD, `og:site_name`). Add or remove a site by editing its row in the list.
- `icon.svg`: the mark. The PNG icons are rendered from it.
- `favicon.ico`: 16, 32 and 48 px. The two small sizes use a simpler cut of the mark, without the underscore.
- `robots.txt`: lists this site's sitemap and OwlLuna's. Crawlers read `robots.txt` only at the root of a hostname.
- `googled5ac35559378b6b6.html`: Search Console's verification file.
- `.nojekyll`: serves the files as they are.
